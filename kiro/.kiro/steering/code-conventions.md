# Code Style & Conventions

## Python

Follow [PEP 8](https://peps.python.org/pep-0008/) for all Python code.

Key points:
- `snake_case` for functions, variables, and modules
- `PascalCase` for classes
- `UPPER_SNAKE_CASE` for constants
- 4-space indentation
- Maximum line length of 79 characters (99 for non-docstring lines is acceptable in practice)
- Use type hints for function signatures

## R

Follow [Google's R Style Guide](https://google.github.io/styleguide/Rguide.html) for all R code.

Key points:
- `BigCamelCase` for functions
- `snake_case` for variables
- Do not use `attach()`
- Use `<-` for assignment, not `=`
- Explicit `return()` statements in functions
